# 近接VC … VPS（ConoHa VPS・Ubuntu）の始め方

> 制作: MaYo (mayo01297)　／　二次配布禁止

> **このページがおすすめの形です**: サイトと Bot は Cloudflare（`https://<Worker の名前>.workers.dev/`）のまま、VPS には「リレーと音声の中継」だけを入れます。
> 世界中の人が、サイトをひらいて部屋番号を入れるだけで使えます。ホストはワールドで `/wsserver ws://<VPS の IP>/new` を送るだけです。
>
> **前にこのスクリプトを入れた VPS も、もう一度 3 のコマンドを実行してください**（リレーが v1.3.0 になり、マイクラで部屋を作る `/new` が使えるようになります）。
>
> （上級者向け: 自分のドメインを持っていて、サイトごと VPS に引っ越すときは [PUBLIC_SERVER.md](PUBLIC_SERVER.md)）

月額が決まっている VPS 1 台に、次の 2 つをコマンド 1 つで入れます。

| 入れるもの | 何のため | ポート |
|---|---|---|
| **近接VC リレー** | Minecraft の `/wsserver` を受けて、Cloudflare の Bot（Worker）に中継する（Minecraft は Cloudflare に直接つなげないため） | TCP 80 |
| **音声の中継（TURN）** | 「サイトで近接VC」の声が、ブラウザどうしで直接つながらない人（学校・会社の Wi-Fi、スマホの回線など）のため | TCP/UDP 3478・UDP 49160〜49200 |

```
Minecraft ──ws://VPSのIP/v/…──▶ VPS（リレー） ──wss://──▶ Cloudflare（Bot・部屋）
ブラウザ ◀──位置・つなぎ方── Cloudflare（部屋）
ブラウザ ◀────── 声 ──────▶ ブラウザ（つながらないときは VPS の TURN を通る）
```

## 0. 先にやっておくこと（Cloudflare 側）

1. 新しい `cloudflare` フォルダの中身を GitHub にアップロード（いつもの更新と同じ）→ Cloudflare が自動でデプロイ
2. サイトの `/setup/` が「設定ずみです」になっていること（Bot のトークンを入れたもの）
3. Bot のトークンを手もとに用意する（ないときは Discord Developer Portal →「Bot」→「Reset Token」→ `/setup/` の「トークンを入れ直す」で入れ直す）

## 1. VPS の IP アドレスを確認する

1. [ConoHa のコントロールパネル](https://manage.conoha.jp/) にログイン →「VPS」
2. 左のメニューの「**サーバー**」→ サーバーリストの **`vps-2026-…`** をクリック
3. 「**ネットワーク情報**」の **IPアドレス（IPv4）** をメモする（例: `160.251.12.34`）

## 2. ポートをあける（ConoHa のセキュリティグループ）

ConoHa の VPS は、最初は SSH（ポート 22）しかあいていません。

1. 左のメニューの「**セキュリティ**」→「**セキュリティグループ**」→ 新しく作る（名前: `mayo-vc`）→「保存」
2. セキュリティグループリストの `mayo-vc` をクリック →「**＋**」で、次の 4 つを 1 つずつ足す（それぞれ「決定」）

   | 通信方向 | イーサタイプ | プロトコル | ポート | IP/CIDR |
   |---|---|---|---|---|
   | IN | IPv4 | TCP | `80` | `0.0.0.0/0` |
   | IN | IPv4 | TCP | `3478` | `0.0.0.0/0` |
   | IN | IPv4 | UDP | `3478` | `0.0.0.0/0` |
   | IN | IPv4 | UDP | `49160-49200` | `0.0.0.0/0` |

   - 4 つ目で `49160-49200`（範囲）が入れられないときは、**プロトコル UDP・ポートを空（全部）**にしてください。サーバーの中のファイアウォール（ufw。3 のコマンドが設定します）で、使うポートだけに絞ります
   - 「IP/CIDR」が空でよい画面なら、空でもかまいません（どこからでも）
3. 左のメニューの「**サーバー**」→ `vps-2026-…` →「**ネットワーク情報**」→「セキュリティグループ」の行の右の**えんぴつ**→「**＋**」→ `mayo-vc` を選ぶ →「**保存**」
   - 最初から入っているグループ（SSH 用など）は**外さない**でください（外すと SSH でログインできなくなります）

## 3. VPS にログインして、コマンドを 1 つ貼る

1. サイトの **`/setup/`** をひらく →「🖥 **VPS（ConoHa など）にリレーと音声の中継を入れる**」
   - Bot のトークンを入れて「**VPS に貼るコマンドを作る**」→ 黒い枠のコマンドを「**コピー**」
   - コマンドは `curl -fsSL https://…/download/vps-setup.sh | sudo bash -s -- … …` の形です（中に音声の中継の合言葉が入っているので、人に見せない）
2. Windows の「**ターミナル**」か「**PowerShell**」をひらいて、次を入力して Enter（IP は 1 でメモしたもの）
   ```
   ssh root@160.251.12.34
   ```
   - はじめてのときは `Are you sure you want to continue connecting (yes/no/[fingerprint])?` と出るので **`yes`** と入力して Enter
   - `password:` と出たら、**VPS を買ったときに決めた root パスワード**を入力して Enter（入力しても画面には何も出ませんが、入っています）
   - `root@vps-…:~#` のように出たらログインできています
   - SSH がうまくいかないときは、ConoHa のサーバーの画面の「**コンソール**」からでもログインできます（ユーザー名 `root`）
3. 1 でコピーしたコマンドを**右クリックで貼り付けて** Enter → 2〜3 分待つ
4. 最後にこう出れば完了です
   ```
   ==================================================
    ✅ 完了しました

     リレーのアドレス:  160.251.12.34
       → サイトの /setup/ の「📡 リレーのアドレス」に入れて「保存してためす」
   ==================================================
   ```
5. `exit` と入力して Enter（ログアウト）

## 4. Bot にリレーのアドレスを教える

1. サイトの **`/setup/`** →「📡 **リレー（中継サーバー）のアドレスを入れる**」
2. VPS の IP（例: `160.251.12.34`）を入れて、Bot のトークンを入れて「**保存してためす**」
3. 「✓ リレーが動いています（MaYoVCRelay v1.3.0・中継先: …）」と出れば OK

これで、Discord の `/vc key` も「サイトで近接VC」も、`/wsserver ws://160.251.12.34/v/…` のコマンドになります（PC のアプリは要りません）。

## 5. サイトで近接VC を使う

1. **ホスト**（ワールドを開く人）: ワールドの設定で「**チートを有効にする**」をオン → ワールドに入って、チャットで **`/wsserver ws://160.251.12.34/new`**（VPS の IP）を送る
   - ゲームのチャットに **6 けたの部屋番号** が出ます（作った人にだけ「管理キー」も出ます）
2. **みんな**（ホストも）: サイトの「🎙 近接VC」→「**サイト版**」で部屋番号を入れて「この部屋に入る」→「**自分を選択**」で自分の名前をえらぶ（ゲームに出ていない人は「観戦者」）
3. 「**🎧 ボイスチャットを開始**」を押して、マイクを「許可」→ 近くの人の声が聞こえます
   - マイク音量・立体音響のオン/オフ・再接続・退出のボタンがあります
   - なりすましが心配なときは、マイクラのチャットで `!vc 6けたの数字` の本人確認もできます
   - 「🔒 管理者設定」（管理キー）で、声が届く距離・人狼・観戦者のルール・入り方を変えられます

- 近いほど大きく、遠いほど小さく、声が届く距離（ホストが選ぶ・最初は 20 ブロック）をこえると聞こえません。相手のいる方向（左右）から聞こえます
- ちがうディメンションの人の声は聞こえません。ゲームにいない人どうし・ワールドが閉じているときは、ロビーとして全員の声が聞こえます
- 死んだ人どうしだけで話すには、ワールドに近接VCアドオン（ワールド用・サイトの「近接VC」ページで作れる）を入れてください（入れなくても、距離の近接VC は使えます）
- ヘッドホンがおすすめです。iPhone は、ブラウザを裏に回すと音が止まることがあるので、Minecraft とは別の端末でひらくのがおすすめです

## 困ったとき

- **`ssh: connect to host … port 22: Connection timed out`** → IP アドレスを確認。ConoHa のセキュリティグループで SSH 用のグループを外していないか
- **`Permission denied, please try again.`** → root パスワードがちがいます（大文字・小文字に注意）。忘れたときは、ConoHa のサポートページで root パスワードの再設定の方法を確認してください
- **ブラウザで `http://VPSのIP/` がひらけない** → 2 の「ポートをあける」（TCP 80）と、「ネットワーク情報」にグループを付けたかを確認
- **最後に ✗ が出た** → もう一度同じコマンドを貼って実行（何回実行しても大丈夫）。それでもだめなら、出てきた文字をスクリーンショットしてください
- **サイトの VC で、名前の横が「つながりません」** → 2 の UDP のルール（3478 と 49160-49200）を確認
- **リレーを新しくしたい・設定を変えたい** → `/setup/` でコマンドを作り直して、VPS でもう一度貼って実行

ログ（どこで止まっているか）を見るとき（VPS にログインして）:
```
journalctl -u mayo-vc-relay -n 30 --no-pager
journalctl -u coturn -n 30 --no-pager
```

## このスクリプトがすること（くわしく）

- Node.js 22（公式のもの・チェックサムを確認）を `/opt/mayo-vc-relay` に入れる
- リレー（`relay.mjs`）を systemd のサービス `mayo-vc-relay` にする（root ではなく専用のユーザーで動く・止まっても自動で起動しなおす）
- coturn（TURN サーバー）を入れて `/etc/turnserver.conf` を書く
  - パスワードは Cloudflare の Worker が合言葉から作る、12 時間だけ使えるもの（`use-auth-secret`）
  - VPS の中や家の中のネットワーク（プライベートアドレス）には中継しない・1 人あたりの数と速さに上限
- ufw（ファイアウォール）で SSH・80・3478・49160〜49200 だけをあける（SSH を先にあけるので、閉め出されません）
- セキュリティの自動更新（unattended-upgrades）を入れる
