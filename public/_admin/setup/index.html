    🔑Discord の Bot のトークンを入れる

    1. トークンを取る: Discord Developer Portal をひらいて、右上の「New Application」→ 名前（例: 近接VC）を入れて「Create」
    2. 左のメニューの「Bot」→「Reset Token」→「Yes, do it!」→「Copy」（このトークンは次の ⑤ で使います）
    3. Public Bot をオンにする: 同じ「Bot」の画面にある「Public Bot」のスイッチをオンにする（世界中の人が、自分のサーバーにこの Bot を呼べるようになります。オフだと、あなたしか招待できません）
    4. インテントを許可する（大事）: 同じ「Bot」の画面の「Privileged Gateway Intents」にある、次の 3 つのスイッチをすべてオンにして、下に出る「Save Changes」を押す
      • PRESENCE INTENT
      • SERVER MEMBERS INTENT
      • MESSAGE CONTENT INTENT
    5. ②でコピーしたトークンを下に貼り付けて「設定する」を押す（Bot の URL の登録や、/vc コマンドの登録は自動でやります）
      1. 招待用の URL を作って、サーバーに入れる: Developer Portal の左のメニュー「OAuth2」→「URL Generator」をひらく
        • 「SCOPES」で bot と applications.commands の両方にチェックを入れる
        • 「BOT PERMISSIONS」で、必要な権限にチェックを入れる: View Channels（チャンネルを見る）・Send Messages（メッセージを送信）・Connect（接続）・Move Members（メンバーを移動）・Manage Channels（チャンネルの管理）
        • いちばん下の「GENERATED URL」に出た URL を「Copy」→ ブラウザでひらいて、Bot を入れたい Discord サーバーを選んで「はい」。（設定が終わると、上の「Bot を Discord サーバーに招待する」ボタンでも、同じ招待ができます）

      このサイトは「設定用のキー」で守られています。VPS にインストールしたときに最後に出たキー（/etc/mayo-vc/env の SETUP_KEY）を入れてください。ほかの人が先に Bot を登録してしまうのを防ぎます。

      トークンは、このサイトのサーバー（Cloudflare の Worker か、あなたの VPS）の中にだけ保存されます。ほかの人には見せないでください。
      世界中の人が自分の Discord サーバーに入れられるようにするには、Developer Portal の「Bot」で「Public Bot」をオンにしてください（オフだと、あなたしか招待できません）。
      Bot を作り直したときや、トークンを Reset したときは、新しいトークンをもう一度入れてください。
      上級者向け: Cloudflare の「設定」→「変数とシークレット」に DISCORD_TOKEN（シークレット）を入れておくと、このページを開くだけで自動で設定されます。

      🖥このサイトは VPS で動いています

      サイト・Bot・近接VC リレー（/wsserver 用）・音声の中継（TURN）が、同じ VPS で動いています。リレーの設定はいりません。

      更新するとき: VPS に SSH でログインして sudo mayo-vc update（新しいサイトのファイルを入れ直します）。
      ようすを見る: sudo mayo-vc status　・　ログ: sudo journalctl -u mayo-vc -n 50

      🖥VPS（ConoHa など）にリレーと音声の中継を入れる（おすすめ）

      月額が決まっている VPS（Ubuntu）に、近接VC リレー（Minecraft の /wsserver 用）と、音声の中継（TURN）（サイトで近接VC の声がつながりにくい人用）を、コマンド 1 つで入れます。

      1. 下にトークンを入れて「VPS に貼るコマンドを作る」
      2. VPS に SSH でログインして（例: Windows の PowerShell で ssh root@VPSのIP）、出てきたコマンドを貼り付けて Enter
      3. 最後に出る「リレーのアドレス」（VPS の IP）を、下の 📡 に入れて「保存してためす」

        コマンドには、音声の中継の合言葉が入っています。人に見せないでください（見られたときは、Cloudflare のシークレット TURN_SECRET に新しい合言葉を入れて、コマンドを作り直して VPS で動かし直します）。

        📡リレー（中継サーバー）のアドレスを入れる

        Minecraft の /wsserver は、Cloudflare の Bot に直接つなぐと、すぐ切れてしまいます（Minecraft が求める返事の形と、Cloudflare の返事の形がちがうため）。 VPS（ConoHa など）・Google Cloud・Railway に置いた「近接VC リレー」を通すと、PC のアプリなしでつなげます。
        ここにリレーのアドレスを入れると、Discord の /vc key や「サイトで近接VC」で出るコマンドが /wsserver ws://リレーのアドレス/v/接続コード に変わります。

        いまの設定: 確認しています…

          VPS（ConoHa など）: VPS の IP アドレス（例: 160.251.1.2）。上の 🖥 のコマンドで入れたときは、ポート番号はいりません。
          Google Cloud の VM: VM の外部 IP（例: 34.82.1.2）か、それに向けた独自ドメイン（例: vc.example.com）。ポート 80 で動かしているときは、ポート番号はいりません。
          Railway: 「Settings」→「Networking」→「TCP Proxy」に出るアドレス（〜.proxy.rlwy.net:12345）を、: のあとのポート番号まで。独自ドメインなら vc.example.com:12345（Railway のポート番号）。
          空にして保存すると、リレーを使わない案内（近接VC コネクター）に戻ります。トークンは確認に使うだけで、ここでは保存しません。
          上級者向け: Cloudflare の変数 RELAY_HOST（wrangler.toml の [vars]）に入れると、そちらが優先されます。

          🌏（上級者向け）VPS でサイトごと動かす（自分のドメインを持っているとき）

          ふつうは使いません（このサイトは Cloudflare のまま、上の 🖥 でリレーと音声の中継だけ VPS に入れれば十分です）。
          Cloudflare の無料プランの上限が足りなくなったときに、このサイト・Discord Bot・リレー・音声の中継をまとめて VPS に引っ越すためのものです。 自分のドメイン（例: vc.example.com）を VPS の IP に向けてから使ってください（https の証明書は自動・無料）。

          1. VPS の会社の「セキュリティグループ」で、22・80・443/TCP、3478/TCP・UDP、49160-49200/UDP をあける
          2. VPS に SSH でログインして（例: Windows の PowerShell で ssh root@VPSのIP）、下のコマンドを貼り付けて Enter（5 分くらい）
          3. 最後に出る「サイトの URL」の /setup/ をひらいて、出てきた「設定用のキー」と Bot のトークンを入れる
          …

          コマンドに合言葉は入っていません（そのまま人に見せても大丈夫です）。新しい版にするときは、VPS で sudo mayo-vc update。
          VPS で Bot を設定すると、Discord の Bot は VPS のほうで動きます（Cloudflare のほうの Discord の設定・紐付けは引きつがれないので、Discord で /vc setup をやり直してください）。
