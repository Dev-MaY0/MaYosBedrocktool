      🔑Discord の Bot のトークンを入れる

      1. Developer Portal で「New Application」→ 名前を入れて「Create」
      2. 「Bot」→「Reset Token」→「Copy」
      3. 同じ画面で「Public Bot」をオン（オフだと自分しか招待できません）
      4. 「Privileged Gateway Intents」の PRESENCE・SERVER MEMBERS・MESSAGE CONTENT をオン →「Save Changes」
      5. トークンを下に貼って「設定する」
        1. 招待: 上の「Bot を招待する」ボタン、または Portal の「OAuth2」→「URL Generator」で bot・applications.commands と権限（View Channels・Send Messages・Connect・Move Members・Manage Channels）を選んで URL をひらく

        VPS のインストールで出た「設定用のキー」（/etc/mayo-vc/env の SETUP_KEY）も入れてください。

        トークンはサイトのサーバーの中にだけ保存されます（人に見せないでください）。Reset したら入れ直してください。
        上級者向け: Cloudflare のシークレット DISCORD_TOKEN に入れると自動で設定されます。

        🖥このサイトは VPS で動いています

        サイト・Bot・リレー・音声の中継が同じ VPS で動いています（リレーの設定は不要）。

        更新: sudo mayo-vc update　・　ようす: sudo mayo-vc status　・　ログ: sudo journalctl -u mayo-vc -n 50

        🖥VPS にリレーと音声の中継を入れる（おすすめ）

        VPS（Ubuntu）に、リレー（/wsserver 用）と音声の中継（TURN）をコマンド 1 つで入れます。

        1. 下にトークンを入れて「VPS に貼るコマンドを作る」
        2. VPS に SSH で入って（ssh root@VPSのIP）、コマンドを貼って Enter
        3. 最後に出るアドレスを、下の 📡 に入れて「保存してためす」

          合言葉入りなので人に見せないでください（見られたら TURN_SECRET を変えて作り直し）。

          📡リレーのアドレス

          /wsserver は Bot に直接つなぐと切れるので、リレーを通します。入れると、コマンドが /wsserver ws://リレー/v/接続コード になります。

          いまの設定: 確認しています…

            VPS: IP だけ（例: 160.251.1.2）。Railway: 〜.proxy.rlwy.net:12345 のようにポートまで。
            空で保存するとコネクターの案内に戻ります。RELAY_HOST 変数があればそちらが優先。

            🌏（上級者向け）VPS でサイトごと動かす

            サイト・Bot・リレー・音声の中継をまとめて VPS に引っ越します。先に自分のドメインを VPS の IP に向けてください（https は自動）。

            1. ポートをあける: 22・80・443/TCP、3478/TCP・UDP、49160-49200/UDP
            2. VPS に SSH で入って、下のコマンドを貼って Enter（5 分ほど）
            3. 出てきたサイトの /setup/ で、設定用のキーとトークンを入れる
