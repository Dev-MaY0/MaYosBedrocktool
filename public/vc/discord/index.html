Discord 版 近接VC

位置で VC を自動で切り替え

← えらび方　・　Discord なしなら サイト版

⚠ Bot の設定がまだです。サイトを公開した人は設定ページでトークンを入れてください。

⚡ かんたんな流れ
  1. ① で Bot を招待
  2. Discord で /vc setup → 届いたファイルをひらく
  3. ホストは コネクター（Windows）に /wsserver … を貼って「スタート」
  4. ワールド（チートON）で /wsserver ws://127.0.0.1:19131
  5. ワールド（チートON）で、Discord に出た /wsserver ws://…/v/… を送る
  6. 遊ぶ人は /vc link →「🎮 近接VC ロビー」へ

🎙できること

  • 近い人どうしを同じVCに自動で移動（距離は /vc distance）
  • 死んだら死亡者VCへ

※ 声の大きさは距離で変わりません（Discord の仕様）。

4ゲームと Discord をつなぐ

ワールド（ホスト）

  1. チートON・「近接VC BP」をオン
  2. ワールドを開くたびに、チャットで送る
    （キーを入れると出ます）
  3. 「[近接VC] Discord「サーバー名」とつながりました」と出たらOK

つながらないときは接続チェックをひらいたまま送り直してください。

予備: リレーが動かないとき（コネクター・Windows）

ワールド（ホスト・Windows）

Bot に直接つなぐと切れるので、PC の中で中継する「近接VC コネクター」を使います（インストール不要）。

  1. コネクターをダウンロード（.zip）
    中の MaYoVCConnector.exe をひらく（警告が出たら「詳細情報」→「実行」）
  2. これを貼って「スタート」
    （キーを入れると出ます）
  3. チートON・「近接VC BP」をオン
  4. ワールドを開くたびに、チャットで送る
    /wsserver ws://127.0.0.1:19131
  5. 「[近接VC] Discord「サーバー名」とつながりました」と出たらOK

つながらないときは接続チェックをひらいたまま送り直してください。遊ぶあいだはコネクターを開いたままに。

BDS・レンタルサーバー（管理者・最初の1回）

  1. ③ の「近接VC BP」をワールドに入れる（world_behavior_packs.json の例） 
    （BDS用をダウンロードすると出ます）
  2. 実験的機能「ベータ API」をオン
  3. config/default/permissions.json をこうする 
    {
  "allowed_modules": [
    "@minecraft/server-gametest",
    "@minecraft/server",
    "@minecraft/server-ui",
    "@minecraft/server-admin",
    "@minecraft/server-editor",
    "@minecraft/server-net"
  ]
}
  4. 再起動（つながらないとチャットに「[近接VC] Discord の Bot につながりません」）

5遊ぶ人みんながやること

  1. Discord で /vc link（最初の1回）
  2. 確認: ワールドはチャットで !vc 1234 のように送る／BDS は画面の「紐付ける」
  3. 「🎮 近接VC ロビー」に入っておくと、位置で自動で切り替わります
  4. 死んだら「💀 死亡者VC」へ

/Bot のコマンド

コマンドできること
/vc setup 管理者VCを作ってキーを出す
/vc link みんなDiscord とマイクラを紐付け
/vc unlink みんな紐付けを外す
/vc status みんなだれがどのVCにいるか
/vc distance 管理者声が届く距離（4〜128、ふだん20）
/vc reset 管理者全員をロビーに戻す
/vc addon みんなアドオンをもらう
/vc key 管理者コマンドとキーをもう一度見る
/vc rekey 管理者キーを作り直す（見られたとき）
？ 使い方・困ったとき

■ /wsserver でつながらない

  • /vc key で出たコマンドをそのまま送ってください。だめなら設定ページの「リレーをためす」で確認。
  • 近接VC コネクターを使ってください（Bot に直接つなぐと切れます）。
  • 接続チェック（④）をひらいたまま送り直すと、どこで止まっているか分かります。
  • チートON か・コマンドがコネクターと同じか確認。
  • 「設定」→「一般」で WebSocket をオン・「暗号化を要求」をオフにして再起動。
  • ws:// を wss:// にすると、つながることがあります。
  • 学校の Wi-Fi やセキュリティソフトが止めていることも。ちがう回線でためしてください。
  • /vc rekey の後は新しいコマンド（/vc key）を使う。

■ VCが切り替わらない

  • /vc status で状態を見る
  • 先に「🎮 近接VC ロビー」に入る（ほかのVCの人は動かしません）
  • 紐付けていない人は /vc link
  • Bot に「メンバーを移動」の権限があるか確認

■ 近接VCの数

人が増えると「🔊 近接VC 5」… を自動で作ります（最大30）。

■ データ

座標は送りません（同じグループかどうかだけ）。Bot には Discord とマイクラの名前・紐付け・キーを保存します。
